# Fiche produit (packaging → app)

Toute fiche produit Awura suit **5 blocs** dans cet ordre :

1. **Nom du produit**
2. **Bénéfices clés** — 2 à 3 bénéfices, style « Bénéfice 1 – Bénéfice 2 – Bénéfice 3 »
3. **Composition** — ingrédients naturels / bio (+ image composition si dispo)
4. **Utilisation** — mode d’emploi court
5. **QR / lien** — authenticité, tutoriels pose, contenus associés

## UI boutique

La page détail (`/boutique/[slug]`) doit reproduire cette structure.  
Les cartes catalogue (`ProductCard`) restent plus compactes (visuel + nom + prix) ; le détail porte les 5 blocs.

## Packaging « Fibre Royale » (référence)

- Étui kraft premium
- QR intégré (authenticité + tutoriels)
- Positionnement : alternative luxe aux mèches synthétiques
