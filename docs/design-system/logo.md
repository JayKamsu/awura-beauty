# Logo & symbole Duafe

## Symbole seul — Duafe

Peigne traditionnel africain (silhouette stylisée). Élément iconique quand le logo complet ne rentre pas :

- Favicon (version noire)
- Loader / spinner
- Avatar par défaut
- Motif de fond en filigrane (faible opacité, camaïeu palette)
- Icône réseaux → Or (`#E59136`) sur fond clair / transparent
- Profil produit → Blanc sur fond Vert Forêt (cercle)

## Logo complet « AWURA BEAUTY »

Variantes officielles :

| Variante | Usage |
| --- | --- |
| Noir d’ébène | Standard / print clair |
| Vert Menthe Fraîche | Sur fond sombre |
| Or Brillant | Premium |
| Or Brillant sur fond noir | Packaging premium inversé |
| Blanc | Sur fond Vert Forêt |

## Interdits (à respecter dans tout composant)

- ❌ Déformer / étirer le logo
- ❌ Couleurs hors palette officielle
- ❌ Modifier la typographie du logo (« BEAUTY » ne change pas de police)
- ❌ Opacité / transparence sur le logo
- ❌ Fond complexe / chargé sans zone de protection
- ✅ Clear space (respiration) autour du logo
